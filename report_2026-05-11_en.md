## 3. What Needs to Be Done Next

Ordered by dependency — each step unblocks the next.

### Step 1 — Set up the scene
Run **`Tools > Setup Test Scene`** in the Unity Editor. This will populate `SampleScene` with:
- `LiveKitManager` GameObject
- Full canvas UI (VideoDisplay + CameraPanel with button container)

Then save the scene (`Ctrl+S`).

### Step 2 — Generate a LiveKit access token
A JWT token is required for every client connection. Options:

- **LiveKit CLI** (recommended for development):
  ```bash
  livekit-server --dev  # starts server + prints dev token
  # or
  lk token create --api-key <key> --api-secret <secret> --join --room <room> --identity <id>
  ```
- **Python/Node script** using the LiveKit server SDK

Set the token in the `LiveKitManager` Inspector field before pressing Play.

### Step 3 — Connect to the running LiveKit server
Ensure the `streaming-server` repo is running (Docker + LiveKit). Then:
1. Set `serverUrl` to `ws://<server-ip>:7880` in the Inspector
2. Paste the generated token into the `token` field
3. Press Play and verify the `OnConnected` event fires (add a `Debug.Log`)

### Step 4 — Verify video stream reception
With at least one FFmpeg stream publishing to the LiveKit room:
1. Check that `OnVideoTrackAvailable` fires and the camera button appears
2. Click the button — `CameraStreamPlayer` should subscribe and show the feed on the `RawImage`

### Step 5 — Add connection status UI (recommended before thesis demo)
Add a small overlay text or icon showing:
- Connecting…
- Connected (green)
- Disconnected / error (red) with a reconnect button

### Step 6 — Persistent configuration
Move `serverUrl` and `token` out of the Inspector into a `Resources/config.json` or a `ScriptableObject` asset so they survive between editor sessions and can be set without recompiling.

### Step 7 — Build and test standalone
Configure build settings (File > Build Settings):
- Platform: Windows (PC, Mac & Linux Standalone)
- Architecture: x86\_64
- Set a product name and company name in Player Settings

Build and test outside the editor to catch any platform-specific issues.
